Acerca del sitio

Conozca el propósito, las características y las tecnologías utilizadas en este proyecto.

Proyecto académico

Objetivo del sitio

Este sitio fue desarrollado para presentar los servicios, trabajos e información del Taller de Precisión y Soldadura Castillo.

También forma parte del proyecto programado del curso Diseño de Aplicaciones Web de la Universidad Técnica Nacional.

El proyecto permite aplicar de manera práctica conceptos de HTML, CSS, Bootstrap, JavaScript y consumo de servicios web.

Características principales

  • Navegación entre páginas HTML.
  • Diseño responsive con Bootstrap.
  • Galería de trabajos.
  • Contenido de audio y video.
  • Formulario de contacto.
  • Ubicación y cálculo de rutas.

Tecnologías utilizadas

Tecnologías utilizadas para desarrollar el proyecto.

Estructura

HTML5 para crear la estructura semántica, los formularios y el contenido multimedia.

Presentación

CSS3 y Bootstrap para aplicar colores, estilos, componentes y diseño responsive.

Programación

JavaScript, jQuery, JSON y una API REST para validaciones, interacción y carga de información.

El proyecto incorpora JavaScript para validaciones e interacciones, archivos JSON para cargar servicios y trabajos, jQuery para manipular elementos del DOM y una API REST para convertir pulgadas a milímetros.
